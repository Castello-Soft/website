# CastelloSoft

Site institucional estático para `castellosoft.com.br`. Não precisa de build nem de dependências para publicação.

## Prévia local

Abra `index.html` com dois cliques. Os arquivos de estilo, script e imagens usam caminhos relativos e carregam sem servidor.

## Publicação

Publique o conteúdo desta pasta em uma hospedagem estática. O arquivo `CNAME` está preparado para GitHub Pages; configure o DNS do domínio na hospedagem escolhida antes de ativá-lo.

## Conteúdo

- `index.html`: texto, estrutura, SEO e links de contato.
- `assets/style.css`: layout responsivo.
- `assets/site.js`: menu móvel e evolução ilustrativa do ticket.
- `assets/factory-hero.webp` e `assets/product-review.webp`: visuais ilustrativos criados para o site.
- `assets/fink-logo.webp` e `assets/fink-post.webp`: marca pública e imagem da publicação da Fink indicada no briefing.
- `assets/favicon.svg`: ícone de navegador; a marca visível é o wordmark no cabeçalho.
- `assets/og.png`: imagem de compartilhamento social.

O fluxo ilustrativo usa dados fictícios, conforme indicado na própria página. Nenhuma informação de cliente foi incluída na demonstração.
